# Armazém Ripamonti

Site oficial do **Armazém Ripamonti**, projeto real desenvolvido pela **Olegario Tech**.

## Status
Em desenvolvimento.

## Branch de trabalho
`site-v1`

## Direção inicial
- experiência mobile-first;
- presença digital local;
- integração com WhatsApp;
- ofertas e destaques comerciais;
- localização e horário;
- identidade oficial do Armazém Ripamonti;
- SEO local e performance.

## Regra do projeto
Nenhum dado comercial do cliente deve ser presumido. Endereço, telefone, horários, entregas, categorias e demais informações serão adicionados somente após confirmação do proprietário.
